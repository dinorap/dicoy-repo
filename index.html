VCAM — Bắt đầu

Làm đúng 5 bước dưới đây. Mất khoảng 30–45 phút. Cần: máy tính + iPhone 7 + cáp.

1

Tải công cụ (trên máy tính)

Chỉ cần tải TrollRestore (bước này dùng máy tính). Dopamine tải sau, trên iPhone.

TrollRestore (macOS)đang chuẩn bị… Bản mới nhấtgithub.com/JJTech0130/TrollRestore

Windows? Tải TrollRestore.exe ở link "Bản mới nhất" (cần iTunes).

2

Cài TrollStore (máy tính + iPhone)

  1. Cắm iPhone → bấm Trust trên iPhone.
  2. Chạy TrollRestore → gõ Tips → Enter.
  3. Chờ iPhone tự khởi động lại (1–3 phút).
  4. Mở app Mẹo/Tips → Install TrollStore.
  5. Mở TrollStore → Settings → Install Persistence Helper → chọn Tips.

Trước bước này phải tắt Find My iPhone (Cài đặt → Apple ID → Find My).

3

Cài Dopamine → bật Jailbreak

Dopamineđang chuẩn bị… Bản mới nhấtellekit.space/dopamine
  1. Tải Dopamine trên iPhone → mở bằng TrollStore → Install.
  2. Mở Dopamine → Jailbreak → chờ respring.
  3. Nếu hiện Apply Workaround → bấm → mở lại Dopamine → Jailbreak lần nữa.
4

Thêm nguồn VCAM

Trong Sileo (Dopamine cài sẵn) → Sources → nút + → dán URL:

https://<bạn>.github.io/<repo>/

Sau đó Refresh nguồn → mở gói VCAM → Get → Respring.

5

Dùng

  1. Mở Camera (hoặc BeautyCam / Google).
  2. Bấm đồng thời nút tăng âm lượng + nút nguồn.
  3. Chọn Chọn video… → chọn clip → chọn 5 hoặc 10 phút.
  4. Chụp/quay bình thường; mở Ảnh kiểm tra file mới.

Tắt: bấm lại tổ hợp → Dừng ngay, hoặc Cài đặt → VCAM → Tắt tất cả.

CameraBeautyCam Google Lens

Chỉ dùng trên thiết bị của bạn. Không dùng cho xác thực danh tính / liveness / KYC.

Không thấy menu khi bấm nút tăng âm lượng + nút nguồn?

Kiểm tra Dopamine đang bật (mở Dopamine → Jailbreak). Sau khi cài VCAM phải respring.

Sileo không thấy VCAM?

Bấm Refresh ở nguồn. Kiểm tra URL có dấu / ở cuối. Thử đóng mở lại Sileo.

Máy khởi động lại thì mất jailbreak?

Đúng — Dopamine là bán vĩnh viễn. Mở Dopamine → Jailbreak lại là được, không mất dữ liệu.
